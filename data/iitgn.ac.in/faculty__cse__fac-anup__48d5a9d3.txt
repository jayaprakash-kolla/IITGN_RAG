### Current Projects

- Secure Exam OS: An open, hardened Ubuntu image and toolchain for conducting online exams and contests in labs. It restricts access to AI assistants and unapproved sites, standardises the lab environment, and can be hardened and reverted per exam with a single script. In use for IITGN courses (ES242, ES248), the ACM India Summer School 2026, and ICPC India contests; deployed by other institutions including IIT Delhi (ZCO 2026). The goal is assessment that is safe against plagiarism yet calm and predictable for students.
- CS Basics Exams: A course-scoped platform that lets teachers create and run coding exams and practice sets. Work in progress.
- Rethinking CS101: Logic Before Syntax: A course design project that separates the logic of instructing a computer from the syntax of any one programming language, using flowcharts as a precise, math-oriented first notation. The aim is problem-solving skill that outlasts any particular language.
