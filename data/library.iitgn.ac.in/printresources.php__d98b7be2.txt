## Print Resources

## Books

 Library books collection consists of research monographs, text-books, conference proceedings, reference books, edited volumes etc., encompassing all disciplines taught and researched at the Institute. In addition, books of general interest but scholarly in nature are being added to develop overall personality of students. This collection is rapidly growing and can be searched using the Online Catalogue. The collection is arranged by Dewey Decimal Classification System.

## Reference Books

 Library has a good collection of reference books which includes encyclopedias, handbooks, dictionaries, directories, manuals, art books, geographical sources etc. These are arranged as separate collection by classification numbers. The Library Online Catalogue can be used to search this collection.

## Print Journals

 The Library subscribes to a good number (126+) of scholarly journals, magazines and newspapers in print form.

#### Current Issues

 Current issues represent the most recent issue(s) of a particular subscribed journal(s). Complete A – Z list of subscribed journals is available here.

#### Back Issues/Bound Volumes

 Once a volume is no longer current and all issues for the year are received, the Library will gather these issues and bind them together into a single volume for the respective year. Only selected journal issues which are of long-term reference value are bound and preserved. Library has 635+ bound journals volumes and they are arranged alphabetically by title in the Library. The updated list is available here.

Additionally, you can browse through the collection here.

#### Newspapers

 The Library subscribes to 17 newspapers in print ( for main and mini-library) and along with this, Library also has access to the PressReader which is a very popular digital newspaper & magazine distribution and technology platform that provides access to 7000+ premium newspapers and magazines, in 60+ languages, from 120 countries.

## Technical Reports

 Library is in the process of developing the collection technical reports of interest to IITGN community. Currently, we have a small collection of 450+ MCEER Technical Reports in print and the same collection is also available freely on web.

## Theses & Dissertations

 As part of Institute’s latest policy, Library has been collecting a soft copy of (electronic - from 22nd May 2026) every Ph.D and M.Tech theses and dissertation submitted to the Institute by the graduating students (Ph.D & M.Tech). The final and approved copy of these theses and dissertations are added to the library collection and details of the same can be searched using Online Catalogue (Up to Thesis Accession No: T01538) and Digital Repository. The hardcopy of these documents (up to 2025) are available for reference within the library premises. This collection is growing gradually and steadily.

## Hindi Collection

 Library has sizable collection of books in Hindi covering different subjects, like history, literature, science & technology. These are kept separately in the stack area of the library and can be searched using Library Online Catalogue. Library is also maintaining a separate list which is updated from time to time and is available here.

## Children Collection

 Considering the demand from the IITGN Community, the Library has started developing a good collection of children books and other reading resources which are most popular and are in demand. This collection is growing steadily and includes books by most popular authors covering varieties of subjects of interest to children. Every item added to this collection is catalogued and classified and arranged as separate collection each book having a Green Spine Label. These books can be searched using Library Online Catalogue. A separate list of these books is also available here.

## Career Corner

 Library has started a Career Corner that consists of books that will help individuals in their professional growth. The collection is at its nascent stage and the entire list of books can be seen here. We also request you to identify and recommend more books to be added in this collection.
